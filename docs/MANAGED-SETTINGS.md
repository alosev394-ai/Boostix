# Управляемые параметры Windows

Boostix должен менять только заранее объявленные параметры и только после
явного согласия. Перед каждой мутацией сохраняются исходное значение, целевое
значение и проверяемая информация для восстановления.

## Стандартный профиль

В стандартный профиль допускаются только обратимые параметры, для которых
текущий компьютер подтвердил поддержку. Фактический экран согласия является
источником истины и перечисляет действия до запроса UAC.

Типовые категории:

- отдельный план питания Boostix, созданный на основе текущего плана;
- таймеры сна/отключения устройств только внутри созданного плана;
- обратимые пользовательские параметры фоновой активности и интерфейса;
- проверяемые параметры планирования Windows, если они поддерживаются текущей
  версией ОС.

HAGS намеренно не переключается автоматически: результат зависит от версии
Windows, видеодрайвера и конкретного GPU. Boostix сохраняет текущее решение
пользователя и не требует перезагрузку ради недоказанного универсального
изменения.

Неподдерживаемый компонент пропускается и попадает в отчёт. Его ошибка не должна
повреждать резервную копию других компонентов.

## Что не входит в стандартный профиль

- отключение Defender, firewall, UAC, обновлений Windows или проверки подписей;
- изменение исполняемых файлов и конфигураций сторонних приложений;
- очистка standby list, принудительное уменьшение памяти других процессов;
- `High` или `Realtime` priority;
- постоянное отключение служб стороннего ПО;
- изменение параметров без процедуры восстановления.

## Восстановление

Восстановление:

1. проверяет целостность и владельца сохранённого состояния;
2. возвращает только значения, которые Boostix действительно изменил;
3. не перезаписывает более позднее изменение пользователя без явного
   разрешения;
4. сохраняет состояние для повторной попытки, если часть обязательных действий
   не завершилась;
5. выдаёт конкретный конфликт вместо бесконечного общего «повторить».

Legacy-состояние предыдущих beta-сборок поддерживается только для безопасного
восстановления и миграции. Оно не используется как шаблон для новых изменений.
