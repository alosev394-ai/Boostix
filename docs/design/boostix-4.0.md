# Boostix 4.0 — решения по редизайну

Автор просил не новую обёртку, а другое приложение: заново продумать,
как оно устроено и что делает, и сменить цвета. Решения ниже принимались
без эскизов, по поручению автора (2026-11-02).

## Почему так

Все сохранившиеся игровые сессии автора включились сами через «Авто»:
CS2, Dota 2, Cyberpunk 2077, Fears to Fathom. Кнопку Boost он не нажимал.
Прежний интерфейс был построен вокруг этой кнопки и датчика, поэтому
любой редизайн выглядел как та же программа в новой обёртке.

Boostix 4.0 строится вокруг того, что происходит на самом деле: игры
пользователя, что Boostix делает с ними сам и как прошла каждая игра.

## Что остаётся

- Движок: подготовка Windows, план питания на время игры, приоритет,
  контроль памяти, откат при сбое, разбор вылетов, журнал Windows.
- Автообновление и канал `update-v3.json` с ключом v2. 3.2.1 обновляется
  до 4.0 сам: установщик `Boostix-Setup-4.0.0.exe`, ProductName «Boostix»,
  версия файла 4.0.0.0, хеш в подписанном манифесте, запуск
  `/updateui --lang=…`.
- Настройки, профили игр и история переносятся без изменений формата
  (отчёт сессии получает версию 5, старые версии читаются).

## Что меняется

### Устройство окна

- Холст 1100×700 вместо 880×560 (на маленьких экранах окно по-прежнему
  уменьшается целиком).
- Вместо боковой панели — верхняя полоса: знак Boostix, разделы «Игры»,
  «Компьютер», «История», «Настройки», справа состояние Boost.
- Главный раздел — «Игры». Датчика и большой кнопки Boost на главном
  экране больше нет.

### «Игры»

- Полка из вертикальных обложек. Источники: сохранённые профили и игры,
  найденные в Steam, Epic Games и GOG. Одна карточка на игру.
- Обложки берутся из локального кэша Steam
  (`appcache\librarycache\<appid>`: `library_600x900.jpg` или
  `library_capsule.jpg`, баннер `library_hero.jpg`, `logo.png`). Сеть не
  нужна. Для остальных игр — заставка Boostix с названием игры.
- На карточке: название, «Авто» включено или нет, когда играли последний
  раз и сколько.
- Справа панель выбранной игры: баннер, кнопка «Играть», переключатель
  «Авто», разбор последней игры и список прошлых.
- «Играть» запускает игру (Steam: `steam://rungameid/<appid>`, иначе сам
  exe) и включает «Авто», так что Boost стартует, когда игра откроется.
- Boost для любой запущенной программы остаётся, но второстепенно:
  кнопка «Boost вручную» над полкой открывает прежний выбор процесса.

### Разбор игры

- Во время сессии Boostix раз в 10 секунд записывает свободную память и
  загрузку процессора (до 720 точек, дальше прореживает).
- После игры: длительность, график за всю игру с отметками важных
  моментов, три вывода простыми словами (хватило ли памяти, были ли сбои,
  совет).

### Во время игры

- Пока идёт Boost, под верхней полосой видна строка «Сейчас»: игра,
  время, свободная память, загрузка процессора и кнопка «Остановить».

### «Компьютер», «История», «Настройки»

- «Компьютер» объединяет проверку ПК, фоновые программы, файл подкачки и
  первичную настройку Windows.
- «История» — все сессии с маленькими графиками, по нажатию открывается
  разбор.
- «Настройки» — прежние переключатели в новом виде.

## Цвета: «Gulf»

Гоночная ливрея: тёмно-синий, голубой и оранжевый. Обложки игр дают
яркость, интерфейс остаётся спокойной сценой.

| Роль | Цвет |
|---|---|
| Окно | #0B1726 |
| Полоса и панели | #0F1E30 |
| Поверхность | #14273D |
| Приподнятая | #1B3150 |
| Граница | #2A4766 |
| Текст | #EEF4FA |
| Вторичный текст | #A8BDD3 |
| Приглушённый | #7A93AD |
| Главное действие (Играть, Boost) | оранжевый #FF7A2F, текст на нём #0B1726 |
| Данные и выделение | голубой Gulf #8FCDF0 |
| Успех | #4FD6A0 |
| Предупреждение | жёлтый #FFD24A |
| Ошибка | #FF5C6C |

Шрифты прежние: Bahnschrift для заголовков и чисел, Segoe UI Variable для
текста. Без градиентов, свечения и заглавных надписей. Стекло Windows 11
остаётся, тон — тёмно-синий.

Темы оформления сохраняются, набор новый: «Gulf» (по умолчанию) и ещё три.

## Картинки

Codex генерирует заставки для игр без обложек (несколько абстрактных
вариантов в цветах Gulf) и иллюстрацию пустой полки. Картинки встраиваются
в exe.

## Проверка

- Весь набор тестов, включая новые на полку, обложки, запись графика и
  разбор.
- Отдельная проверка: код обновления из выпущенной 3.2.1 принимает
  установщик 4.0 (манифест, хеш, версия, ProductName).
- Снимки экрана каждого раздела в обеих темах окна.
