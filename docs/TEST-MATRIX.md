# Матрица тестирования Boostix 2.0.0

Версия 2.0.0 остаётся **BETA**, пока обязательные строки не подтверждены на
финальном публичном артефакте. Автоматический contract-test подтверждает только
проверяемое им свойство и не заменяет Windows VM, физический ПК или live update.

Статусы:

- **контракт** — сценарий покрыт автоматической проверкой исходников/компонента;
- **ожидается** — требуется финальный прогон release commit или реальная среда;
- **блокирует stable** — без результата stable-релиз запрещён.

## Публичный update-канал

После публикации live-canary должен скачать `update.json`, `update-v2.json`, все
подписи, versioned/latest/legacy assets и `SHA256SUMS.txt` через публичные URL.
Проверяются RSA, SHA-256, размер, версия, ProductName и фактический Authenticode.
Offline fixture не доказывает доступность публичного канала.

## Stable evidence

Перед снятием BETA обязательны:

- 0 открытых P0/P1 по безопасности и потере данных;
- доверенная Authenticode-подпись каждого EXE с RFC 3161 timestamp;
- 100 последовательных apply → reboot → restore без необратимых изменений;
- не менее 20 физических ПК и 500 часов суммарных сессий;
- не менее 100 полных Boost-сессий;
- три подряд зелёных CI-прогона из чистого checkout;
- install/update success и crash-free sessions не ниже 99%;
- 30 дней RC без нового критического дефекта;
- явное решение по ARM64 и SYSTEM/session 0.
