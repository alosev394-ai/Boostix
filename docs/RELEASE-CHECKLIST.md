# Чек-лист релиза Boostix

Надпись `BETA` снимается только после выполнения всех пунктов с пометкой
**Блокирует stable**. Галочка должна подтверждаться ссылкой на CI, артефакт,
протокол или Issue; устного подтверждения недостаточно.

## 1. Заморозка релиза

- [ ] **Блокирует stable:** назначены версия, commit и подписанный tag.
- [ ] **Блокирует stable:** версия едина в приложении, установщике, манифесте и
  именах артефактов.
- [ ] **Блокирует stable:** release branch принимает только исправления
  подтверждённых блокеров.
- [ ] Составлены release notes и список известных ограничений.
- [ ] Выбран канал публикации: `beta`, `RC` или `stable`.

## 2. Автоматические проверки

- [ ] **Блокирует stable:** GitHub Actions собрал Release из чистого checkout.
- [ ] **Блокирует stable:** `tests/Run-All.ps1` обнаружил и выполнил каждый
  `Test-*.ps1`.
- [ ] **Блокирует stable:** количество обнаруженных и выполненных тестов
  совпадает.
- [ ] **Блокирует stable:** нет failed, timed out или skipped тестов.
- [ ] **Блокирует stable:** получены три последовательных зелёных CI-прогона.
- [ ] Проверены PowerShell syntax, secret scanning и dependency/license notices.

## 3. Подпись и целостность

- [ ] **Блокирует stable:** приложение подписано доверенным Authenticode
  сертификатом.
- [ ] **Блокирует stable:** установщик и деинсталлятор подписаны тем же
  ожидаемым издателем.
- [ ] **Блокирует stable:** подписи имеют RFC 3161 timestamp и статус `Valid`.
- [ ] **Блокирует stable:** подписан манифест обновления.
- [ ] **Блокирует stable:** версия, размер и SHA-256 установщика совпадают с
  манифестом.
- [ ] **Блокирует stable:** транспортный мост для 1.8.x имеет только legacy
  `ProductName`, содержит тот же payload Boostix и не устанавливает старое имя;
  каждая из двух URL/SHA-256/size троек описывает свой разрешённый подписанный
  файл без смешивания метаданных.
- [ ] Опубликованы SHA-256 и SBOM.
- [ ] Release workflow использует минимальные права и закреплённые commit SHA
  внешних Actions.
- [ ] Резервная копия ключей проверена; процедура ротации и отзыва задокументирована.

## 4. Безопасность системных операций

- [ ] **Блокирует stable:** каждый системный компонент имеет точную резервную
  копию и проверенный откат.
- [ ] **Блокирует stable:** пути установки, update, backup, restore и uninstall
  ограничены allowlist.
- [ ] **Блокирует stable:** junction, symlink и другие reparse point безопасно
  отклоняются.
- [ ] **Блокирует stable:** отказ в UAC не оставляет частичное состояние.
- [ ] **Блокирует stable:** запуск UAC под другой учётной записью не смешивает
  профили пользователей.
- [ ] **Блокирует stable:** пользовательские изменения после Boost не
  перезаписываются при восстановлении.
- [ ] **Блокирует stable:** приложение не отключает антивирус, firewall, UAC или
  проверку подписей.
- [ ] Нет выполнения сетевых команд или неподписанного кода.
- [ ] Пройден приватный security review согласно `SECURITY.md`.

## 5. Установка, update и recovery

- [ ] **Блокирует stable:** чистая установка проверена на каждой поддерживаемой
  Windows.
- [ ] **Блокирует stable:** проверено обновление с каждой поддерживаемой старой
  версии.
- [ ] **Блокирует stable:** сбой на каждой стадии обновления заканчивается
  рабочей старой или новой версией.
- [ ] **Блокирует stable:** offline, timeout, 403/429/5xx и частичная загрузка
  не повреждают установку.
- [ ] **Блокирует stable:** неверные подпись, версия, размер и SHA-256 блокируют
  установку.
- [ ] **Блокирует stable:** деинсталлятор не удаляет данные за пределами
  управляемых каталогов.
- [ ] **Блокирует stable:** удаление блокируется до обязательного восстановления.
- [ ] Проверена экстренная остановка распространения плохого обновления.
- [ ] Проверен staged rollout сначала на RC-группу.

## 6. Функции и честность интерфейса

- [ ] **Блокирует stable:** все действия Boost соответствуют видимым
  переключателям.
- [ ] **Блокирует stable:** не закрываются процессы, которые пользователь
  исключил.
- [ ] **Блокирует stable:** нет обещания гарантированного прироста FPS.
- [ ] **Блокирует stable:** RAM-функция не очищает standby list Windows и не
  уменьшает working set целевого приложения.
- [ ] **Блокирует stable:** отображаемые метрики FPS математически соответствуют
  своим названиям.
- [ ] Необязательные и экспериментальные системные изменения выключены по
  умолчанию либо доказаны на тестовой матрице.
- [ ] Отмена длительной операции оставляет систему в определённом состоянии.
- [ ] Диагностика объясняет RAM, commit, pagefile и VRAM раздельно.

## 7. Визуальная проверка и доступность

- [ ] **Блокирует stable:** пройдены все UI-сценарии из `TEST-MATRIX.md`.
- [ ] **Блокирует stable:** на 1920×1080 при 100/125/150% нет размытия,
  обрезания, смещённых иконок или неравных отступов.
- [ ] **Блокирует stable:** окна установщика и приложения проверены на
  1366×768 и 4K/200%.
- [ ] **Блокирует stable:** клавиатура, Tab-порядок, Enter, Space и Escape
  работают без мыши.
- [ ] **Блокирует stable:** интерактивные элементы имеют AutomationName.
- [ ] **Блокирует stable:** контраст текста и контролов соответствует WCAG AA.
- [ ] Проверены High Contrast, Narrator, Reduced Motion и увеличение текста.
- [ ] Для ключевых экранов приложены эталонные скриншоты.

## 8. Реальные испытания

- [ ] **Блокирует stable:** протестировано не менее 20 разных физических ПК.
- [ ] **Блокирует stable:** накоплено не менее 500 часов сессий.
- [ ] **Блокирует stable:** выполнено не менее 100 полных Boost-сессий.
- [ ] **Блокирует stable:** пройден восьмичасовой непрерывный запуск.
- [ ] **Блокирует stable:** 100 циклов apply → reboot → restore завершились без
  необратимых изменений.
- [ ] **Блокирует stable:** crash-free sessions не ниже 99%.
- [ ] **Блокирует stable:** успешность чистой установки/update не ниже 99%.
- [ ] Проверены CPU/GPU/RAM/pagefile/monitor конфигурации из `TEST-MATRIX.md`.
- [ ] Нет подтверждённого ухудшения производительности за установленным допуском.

## 9. Конфиденциальность, лицензии и поддержка

- [ ] **Блокирует stable:** актуальны `PRIVACY.md`, `SECURITY.md`,
  `SUPPORT.md` и `TROUBLESHOOTING.md`.
- [ ] **Блокирует stable:** продукт, автор и copyright в бинарниках совпадают с
  релизными документами.
- [ ] **Блокирует stable:** проверены права на иконки, шрифты и другие ресурсы.
- [ ] **Блокирует stable:** все сторонние лицензии поставляются с приложением.
- [ ] **Блокирует stable:** диагностический экспорт проверен на персональные
  пути и чувствительные данные.
- [ ] Документированы фактические сроки хранения журналов и истории.
- [ ] Каналы security и обычной поддержки реально доступны.

## 10. Решение о публикации

- [ ] Все stable-блокеры закрыты доказательствами.
- [ ] Открытых P0/P1 по безопасности, восстановлению и пользовательским данным: 0.
- [ ] Последний RC не получал критических изменений не менее семи дней.
- [ ] Артефакты скачаны из публичного канала и повторно проверены на отдельной
  чистой машине.
- [ ] Публичный `Latest` указывает ровно на проверенный versioned installer.
- [ ] Подготовлены rollback-релиз и сообщение пользователям на случай отзыва.
- [ ] Ответственный за релиз дал финальное `GO`.

После публикации:

- [ ] Проверена загрузка и установка публичного артефакта.
- [ ] Проверена автоматическая проверка обновления с предыдущей версии.
- [ ] В течение первых 24 часов контролируются update/recovery обращения.
- [ ] Через 7 дней проведён короткий post-release review.
