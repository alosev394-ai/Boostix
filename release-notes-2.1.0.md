# Boostix 2.1.0 BETA

Boostix 2.1.0 — полностью новый интерфейс. Вместо маленького окна и отдельного
«Центра» поверх него теперь одно окно с боковым меню, где все разделы на виду.
Логика сессии, защитные механизмы и формат отчётов остались прежними; заодно
исправлены несколько ошибок, найденных при ревью кода. Это предварительный
prerelease, а не stable-релиз.

## Новый интерфейс

- **Одно окно 880×560 с боковым меню**: Главная, Система, Фон, Отчёты, Игры,
  Настройки. Внизу меню всегда видно состояние сеанса и время Boost.
- **Главная страница**: карточка игры с её настоящей иконкой, круглая кнопка
  Boost с цветом состояния (фиолетовый — готов, вращающаяся дуга — запуск,
  зелёный — активен), карточка «Система» с заполнением оперативной,
  видео- и виртуальной памяти и итогом проверок, плитки «Сеанс», «Запас памяти»,
  «Время сеанса».
- **Список игр** открывается под карточкой игры и показывает иконку, имя, PID и
  EXE каждого окна.
- **Разделы** собраны из карточек и списков; кнопки действий вынесены на
  отдельную панель внизу и больше не перекрывают прокручиваемый текст.
- **Настройки** переписаны без двойного отрицания: «Закрывать при запуске Boost»
  с выключенными по умолчанию переключателями вместо «Не закрывать …» с
  включёнными. Сохранённые настройки пользователей читаются без изменений.
- **Понятные названия**: «Запас памяти» вместо «COMMIT», «Замер FPS» вместо
  «Proof Mode», «Фон» и «Отчёты» вместо «Влияние» и «Эффект». Подписи в обычном
  регистре; заголовки из старых отчётов показываются так же.
- **Диалоги** первой настройки и обновления — карточки по центру на
  затемнённом фоне вместо полноэкранного текста.
- **Новая иконка** и знак: фиолетово-розовый квадрат с молнией. Установщик
  переведён на ту же палитру и шрифт.
- **Шрифты и цвета**: Bahnschrift (входит в Windows 10 1709+) для заголовков и
  цифр, Segoe UI Variable для текста, тёмная палитра с фиолетовым оттенком.
  Схема высокой контрастности Windows и отключённая анимация по-прежнему
  учитываются.
- Escape на главной странице больше не закрывает приложение; Escape в разделе
  возвращает на главную. Ctrl+Tab переключает разделы, Enter запускает и
  останавливает Boost.
- На маленьких экранах и при масштабе 200% окно целиком уменьшается
  пропорционально, без перекомпоновки и обрезки.

## Исправления

- Игры, запущенные от имени администратора или защищённые античитом, снова
  видны в списке «Выбрать игру». Путь к EXE, проверка «процесс жив» и
  счётчики Session Guard теперь читаются через ограниченный доступ
  `PROCESS_QUERY_LIMITED_INFORMATION`, который Windows выдаёт таким процессам.
- Если Windows не даёт изменить приоритет игры, это записывается в отчёт сеанса
  один раз, а не каждую секунду с перезаписью файла сеанса.
- Таймаут запуска Boost считается по UTC: переход на летнее время больше не
  обрывает и не затягивает запуск. Причина неудачного запуска скрипта подготовки
  записывается в `crash.log`.

## Удалено

- Неиспользуемый старый сервис «очистки памяти» (около 500 строк) и старая
  панель переключателей главного окна.
- Двухразмерный режим окна (460 и 620 DIP) и компактная перекомпоновка: вместо
  них одно окно с равномерным масштабированием.

## Совместимость

Цель beta-канала — Windows 10/11 x64 в интерактивной пользовательской сессии;
требуется .NET Framework 4.8. Ограничения перечислены в
[`docs/KNOWN-ISSUES.md`](docs/KNOWN-ISSUES.md).

## Почему это всё ещё BETA

Артефакты не имеют доверенной Authenticode-подписи. RSA-подпись
update-манифеста и SHA-256 защищают целостность канала, но не заменяют подпись
издателя Windows. Поэтому SmartScreen, WDAC или корпоративная политика могут
показать неизвестного издателя либо заблокировать запуск. Не отключайте защиту
Windows ради установки.
