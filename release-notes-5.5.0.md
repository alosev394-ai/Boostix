# Boostix 5.5.0

У каждой игры появилась история: что повторяется от игры к игре.

## Что нового

- **История игры.** Кнопка «История» на карточке игры и в разборе. Наверху вывод
  одной фразой, например «Памяти не хватает почти в каждой игре». Под ним график:
  сколько свободной памяти осталось в каждой игре и где проходит порог нехватки.
  Ниже программы, которые занимали память, когда её не хватало, и как часто. Любую
  из них, кроме нужных игре, можно закрывать на время игры одной кнопкой. Внизу все
  игры по порядку, каждая открывает свой разбор.

## Что исправлено

- **FACEIT больше не предлагается закрыть.** Без него не начнётся матч FACEIT. Если
  FACEIT уже был в списке закрываемых программ, Boostix его пропустит. То же касается
  Riot Vanguard, Easy Anti-Cheat и BattlEye.
- **Прокрутка разбора.** Длинный разбор больше не заезжает под вкладки окна.

## Обновление

Установленные 2.1.x–5.4.1 получат 5.5.0 через автообновление. Настройки, профили
игр и история сохраняются. С 2.0.0 и раньше нужно один раз установить вручную:
скачайте `Boostix-Setup-5.5.0.exe` со страницы релиза и сверьте SHA-256 с
`SHA256SUMS.txt`.

## Что важно знать

- История строится по последним 120 играм с Boost, всех вместе. Список программ есть
  только у игр, сыгранных на 5.1 и новее, и только у тех, где памяти не хватало.
- Файлы Boostix пока **не подписаны сертификатом Authenticode**. Windows может
  показать предупреждение SmartScreen о неизвестном издателе. Бесплатная подпись
  через SignPath Foundation подготовлена и включится после одобрения проекта:
  [`CODE_SIGNING.md`](CODE_SIGNING.md).
- Boostix не обещает определённый прирост FPS: результат зависит от компьютера,
  драйверов, игры и сцены.

## Для разработчиков

- Boostix собирается компилятором C# из Visual Studio Build Tools вместо
  компилятора внутри .NET Framework: можно писать на C# 12 вместо C# 5. Программа
  по-прежнему работает на .NET Framework 4.8. Сборка останавливается, если
  компилятор видит обращение к пустому значению.

Нужны Windows 10 или 11 (64-бит) и .NET Framework 4.8.
