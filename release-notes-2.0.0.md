# Boostix 2.0.0 BETA

Boostix 2.0.0 переводит Boost из набора общих действий в управляемую игровую
сессию: с точной целью, наблюдаемым состоянием и проверяемым сравнением. Это
предварительный prerelease, а не stable-релиз.

## Новое

### Точная цель и Session Guard

- Целевой процесс закрепляется по PID, времени запуска и полному пути.
- Повторное использование PID другим процессом безопасно отклоняется.
- Session Guard наблюдает доступную физическую память, commit reserve, файл
  подкачки и память выбранной цели.
- Гистерезис и cooldown отделяют устойчивое давление памяти от единичного
  всплеска.

### Background Impact

- Добавлена read-only оценка влияния фоновых приложений.
- Закрытие доступно только после явного выбора пользователя.
- Используется только штатный запрос на закрытие. Force-kill отсутствует.

### Proof Mode

- Добавлено управляемое A/B-сравнение из четырёх 60-секундных этапов:
  Baseline → Boost → Boost → Baseline.
- Контрольная точка позволяет продолжить незавершённый сценарий после
  перезапуска.
- Итог показывает FPS, 1% low, P95 и вариативность с учётом разброса парных
  прогонов.
- Результат действителен только для закреплённой цели и неизменённого сценария;
  Boostix не превращает его в обещание прироста на другом ПК или в другой сцене.

### Crash Assistant

- Завершение отслеживается для точного выбранного процесса.
- Связанные по времени записи Windows Error Reporting и Application Error
  отображаются как свидетельства.
- Нормальное завершение не объявляется сбоем, а найденная запись не выдаётся за
  доказанную первопричину.

### План питания только на время сессии

- Разрешённый план Boostix включается только при работе от сети переменного тока.
- После сессии восстанавливается точный предыдущий GUID.
- Если активный план был изменён пользователем или Windows во время сессии,
  Boostix сохраняет это внешнее изменение.
- После аварийного завершения выполняется ограниченная проверка собственного
  маркера сессии перед восстановлением.

## Установка и обновление

- Усилена классификация сетевых, локальных и криптографических ошибок.
- Учтены системный proxy, TLS/redirect, ограниченные повторы, неизвестная длина
  ответа, нехватка места, временная блокировка файлов и отмена UAC.
- Сохраняются проверка RSA-манифеста, размера, SHA-256, PE, версии и идентичности
  продукта, защищённый staging, health handshake и транзакционный rollback.
- Путь миграции рассчитан на установленные версии 1.3–1.9. Старые клиенты нельзя
  обновить задним числом, поэтому при недоступности их endpoint остаётся ручной
  versioned installer со сверкой опубликованного SHA-256.

Эти изменения расширяют автоматические контракты, но не заменяют E2E-проверку
каждого сценария на чистых Windows 10/11 VM. Подтверждённые и ожидающие сценарии
перечислены в [`docs/TEST-MATRIX.md`](docs/TEST-MATRIX.md).

## Безопасные ограничения

В 2.0.0 отсутствуют:

- очистка standby list и системного файлового кэша;
- working-set trim целевого приложения;
- принудительный GC ради показного уменьшения RAM;
- принудительное завершение фоновых приложений;
- внедрение в процессы, изменение игровых файлов или обход anti-cheat.

## Совместимость

Цель beta-канала — Windows 10/11 x64 в интерактивной пользовательской сессии.
Windows ARM64, SYSTEM/session 0, полный набор корпоративных proxy/WDAC/EDR и все
варианты mixed-DPI ещё не подтверждены. Полный список ограничений находится в
[`docs/KNOWN-ISSUES.md`](docs/KNOWN-ISSUES.md).

## Почему это всё ещё BETA

Артефакты 2.0.0 не имеют доверенной Authenticode-подписи. RSA-подпись
update-манифеста и SHA-256 защищают целостность канала, но не заменяют подпись
издателя Windows. Поэтому SmartScreen, WDAC или корпоративная политика могут
показать неизвестного издателя либо заблокировать запуск.

До code signing, полного VM/lifecycle-прогона и накопления RC-статистики версия
должна публиковаться только как **2.0.0 BETA prerelease**. Не отключайте защиту
Windows ради установки.
