# Boostix 3.1

Boostix 3.1 меняет внешний вид: на Windows 11 окно стало стеклянным, а цвета
сменились на тёмно-бирюзовый и лимонный.

## Что нового

- **Стекло Windows 11.** Окно полупрозрачное: сквозь боковую панель и фон
  видны размытые обои или окна за Boostix. Размытие рисует сама Windows,
  поэтому оно почти не нагружает компьютер. Пока окно не активно, оно
  сплошное, как и другие окна Windows 11.
- **Стекло следует настройке Windows.** Оно работает, когда включены эффекты
  прозрачности: Параметры → Персонализация → Цвета → «Эффекты прозрачности».
  Переключатель срабатывает сразу, перезапускать Boostix не нужно. Без
  эффектов прозрачности, в режиме высокой контрастности и на Windows 10 окно
  остаётся сплошным.
- **Новые цвета.** Тёмно-бирюзовый фон, лимонный цвет для датчика Boost и
  главных кнопок. Предупреждения теперь оранжевые, чтобы не путаться с
  лимонным.
- **Новый значок** программы и установщика в тех же цветах.

## Исправления

- Текст ошибок и красная кнопка стали светлее и лучше читаются на тёмном фоне.

## Обновление

Установленные 2.1.x, 2.2.0 и 3.0.0 получат 3.1 через автообновление. С 2.0.0
и раньше нужно один раз установить вручную: скачайте `Boostix-Setup-3.1.0.exe`
со страницы релиза и сверьте SHA-256 с `SHA256SUMS.txt`.

## Что важно знать

- Файлы Boostix пока **не подписаны сертификатом Authenticode**. Windows
  может показать предупреждение SmartScreen о неизвестном издателе. Не
  отключайте защиту Windows; проверьте, что установщик скачан со страницы
  релиза, и сверьте SHA-256.
- Полная проверка на чистых Windows 10/11 по
  [`docs/TEST-MATRIX.md`](docs/TEST-MATRIX.md) ещё не завершена; открытые
  пункты перечислены в [`docs/KNOWN-ISSUES.md`](docs/KNOWN-ISSUES.md).
- Boostix не обещает определённый прирост FPS: результат зависит от
  компьютера, драйверов, игры и сцены.

Нужны Windows 10 или 11 (64-бит) и .NET Framework 4.8. Стекло — Windows 11
22H2 и новее.
