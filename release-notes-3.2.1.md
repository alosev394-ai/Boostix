# Boostix 3.2.1

Исправления по отчётам реальных игровых сессий на 3.2.0.

## Исправления

- **Приоритет игры.** Boost поднимает приоритет игры, пока она на переднем
  плане. CS2 и Dota 2 меняют свой приоритет сами, и раньше Boost после каждого
  возвращения в игру поднимал его заново. За час CS2 в отчёте набиралось
  девять пар записей «внешнее изменение сохранено» и «Normal → AboveNormal».
  Теперь, если игра сама сменила приоритет, Boost оставляет его как есть до
  конца сессии и пишет об этом в отчёт один раз.
- **Отчёт сессии на языке интерфейса.** Совет про файл подкачки выводился
  по-английски («A fixed-size page file can cap commit…»), как и причина, по
  которой игра пропала из сессии («The selected process has already exited»).
  Теперь оба текста на языке интерфейса.
- **Журнал сбоев в английском интерфейсе.** Каждый запуск оставлял в
  `crash.log` запись «Proof Mode checkpoint was not restored: No saved FPS
  measurement was found». Это обычное состояние, а не сбой, и запись больше
  не появляется.

## Обновление

Установленные 2.1.x–3.2.0 получат 3.2.1 через автообновление. С 2.0.0 и
раньше нужно один раз установить вручную: скачайте `Boostix-Setup-3.2.1.exe`
со страницы релиза и сверьте SHA-256 с `SHA256SUMS.txt`.

## Что важно знать

- Файлы Boostix пока **не подписаны сертификатом Authenticode**. Windows
  может показать предупреждение SmartScreen о неизвестном издателе.
  Бесплатная подпись через SignPath Foundation подготовлена и включится после
  одобрения проекта: [`CODE_SIGNING.md`](CODE_SIGNING.md).
- Boostix не обещает определённый прирост FPS: результат зависит от
  компьютера, драйверов, игры и сцены.

Нужны Windows 10 или 11 (64-бит) и .NET Framework 4.8.
