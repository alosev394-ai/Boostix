# История изменений

## 1.8.1

- Исправлена размытая отрисовка интерфейса на экранах 1920×1080 при масштабе Windows 100%: production-макет больше не уменьшается дробно до 95%.
- Адаптивное уменьшение сохранено для маленькой рабочей области и мониторов с высоким DPI.
- Добавлена регрессионная проверка, требующая точный масштаб 1:1 для стандартного окна 460×552.
- Исправлено имя автора на `Silas Suspect` в интерфейсе, свойствах файлов, установщике и записи Windows «Установленные приложения».

## 1.8.0

- Добавлен живой мониторинг RAM, commit, файла подкачки и видеопамяти по конкретному GPU-адаптеру.
- Центр Boost получил историю последних 10 игровых сессий и сравнение FPS только с предыдущим измерением той же версии GTA.
- Добавлен помощник по сбоям GTA с отдельными рекомендациями для нехватки памяти, драйвера GPU, модов и повреждения данных.
- Добавлен безопасный экспорт диагностического отчёта без персональных путей и секретов.
- Обновление стало транзакционным: новая версия подтверждается только после локальной проверки готовности, а при сбое установщик автоматически восстанавливает предыдущую версию.
- Интерфейс адаптирован к высокой плотности экрана и уменьшенной рабочей области; улучшены отступы, клавиатурная навигация и видимость фокуса.
- Метрика VRAM исправлена: загрузка и ёмкость сопоставляются по LUID одного адаптера, без смешивания iGPU, dGPU и process-specific DXGI budget.
- Пики VRAM внутри сессии также остаются привязаны к одному LUID и не склеиваются при переключении между видеокартами.
- Исправлено различие между отключённым файлом подкачки и недоступной WMI-диагностикой.
- Активная сессия теперь сохраняется в диагностическом экспорте и не заменяется устаревшей копией с диска.
