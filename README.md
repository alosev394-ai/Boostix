# Boostix

Boostix — компактное приложение для безопасной подготовки Windows к высокой
нагрузке. Оно помогает убрать явно выбранные фоновые приложения, временно
поддерживает безопасный приоритет крупного активного окна, показывает состояние
RAM/commit/pagefile/VRAM и сохраняет локальный отчёт о сессии.

Текущий канал — **1.9.0 BETA**. Приложение не обещает гарантированный прирост
FPS: эффект зависит от оборудования, драйверов, температуры, настроек Windows и
фоновой нагрузки.

## Основные возможности

- отдельное подтверждение перед изменением системных параметров;
- транзакционная резервная копия и восстановление только управляемых значений;
- безопасные значения по умолчанию: сторонние приложения не закрываются без
  явного выбора пользователя;
- сначала штатное закрытие выбранного приложения и только затем ограниченный
  принудительный fallback;
- временный приоритет `AboveNormal` только для крупного активного окна с
  восстановлением исходного значения;
- диагностика физической памяти, commit, файла подкачки, VRAM, питания и
  состояния Windows;
- снижение собственного working set Boostix при подтверждённом давлении памяти;
- локальное измерение frame time через закреплённую сборку PresentMon;
- настоящий показатель `1% low`, P95/P99 и длинные кадры;
- сравнение производительности только для явно сопоставимого контекста;
- подписанный RSA-манифест обновлений, SHA-256, проверка размера и версии
  установщика, атомарная замена и rollback;
- безопасное удаление, блокирующее junction, symlink и другие reparse point;
- режим `--safe-mode` для запуска интерфейса и восстановления без запуска Boost
  и первичной системной настройки.

Boostix не внедряется в процессы, не меняет файлы сторонних приложений, не
очищает standby list Windows и не уменьшает working set целевого приложения.
Доступная память Windows уже включает страницы кэша, которые система может
переиспользовать автоматически.

## Сборка

Требования:

- Windows 10/11;
- Windows PowerShell 5.1;
- .NET Framework 4.8 Developer Pack;
- Visual C++ runtime, необходимый поставляемому PresentMon.

```powershell
.\build.ps1
.\tests\Run-All.ps1
```

Результат успешной сборки:

- `dist\Boostix.exe`;
- `dist\Boostix-Setup-1.9.0.exe`;
- `dist\Boostix-Setup-Latest.exe`.

Сборка не считается готовой к публикации, если отсутствует хотя бы один
обязательный тест или любой тест завершился ошибкой.

## Обновления и релиз

Обычная проверка обновлений работает по HTTPS. Перед запуском установщика
Boostix проверяет подпись манифеста, разрешённый канал, размер, SHA-256, версию и
идентичность продукта. Ошибка сети не должна повреждать текущую установку, а
ошибка криптографической проверки всегда блокирует пакет.

Для одноразового перехода установленных версий 1.8.x сборка также публикует
изолированный legacy-транспортный мост. Только его технические метаданные
сохраняют прежнее значение, необходимое строгой проверке старого клиента.
Внутри находится тот же проверенный payload Boostix; интерфейс, путь установки,
EXE и ярлыки остаются Boostix. Поля `installerUrl`, `sha256` и `size` схемы v1
описывают этот мост, а Boostix 1.9+ предпочитает отдельную проверенную тройку
`boostixInstallerUrl`, `boostixSha256`, `boostixSize`. Мост удаляется после
завершения окна поддержки 1.8.x.

Перед публикацией:

1. выполните `tests\Run-All.ps1` из чистого checkout;
2. подтвердите версию всех EXE и имён артефактов;
3. подпишите EXE доверенным Authenticode-сертификатом с RFC 3161 timestamp;
4. сформируйте и подпишите update-манифест;
5. повторно проверьте SHA-256 опубликованных файлов;
6. выполните lifecycle-проверку на чистой Windows.

Полные критерии находятся в
[`docs/RELEASE-CHECKLIST.md`](docs/RELEASE-CHECKLIST.md).

## Данные и безопасность

Boostix работает локально и не отправляет телеметрию. Сетевые запросы
используются только для проверки и загрузки обновления. Диагностический экспорт
создаётся только по действию пользователя.
