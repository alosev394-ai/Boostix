# Boostix

Boostix — компактное приложение для безопасной подготовки Windows к высокой
нагрузке. Оно помогает убрать явно выбранные фоновые приложения, временно
поддерживает безопасный приоритет крупного активного окна, показывает состояние
RAM/commit/pagefile/VRAM и сохраняет локальный отчёт о сессии.

Текущий канал — **1.9.1 BETA**. Приложение не обещает гарантированный прирост
FPS: эффект зависит от оборудования, драйверов, температуры, настроек Windows и
фоновой нагрузки.

## Основные возможности

- отдельное подтверждение перед изменением системных параметров;
- транзакционная резервная копия и восстановление только управляемых значений;
- безопасные значения по умолчанию: сторонние приложения не закрываются без
  явного выбора пользователя;
- сначала штатное закрытие выбранного приложения и только затем ограниченный
  принудительный fallback;
- временный приоритет `AboveNormal` только для крупного активного окна с
  восстановлением исходного значения;
- диагностика физической памяти, commit, файла подкачки, VRAM, питания и
  состояния Windows;
- снижение собственного working set Boostix при подтверждённом давлении памяти;
- локальное измерение frame time через закреплённую сборку PresentMon;
- настоящий показатель `1% low`, P95/P99 и длинные кадры;
- сравнение производительности только для явно сопоставимого контекста;
- подписанный RSA-манифест обновлений, SHA-256, проверка размера и версии
  установщика, атомарная замена и rollback;
- системный proxy, ограниченные повторы загрузки и проверенные резервные
  источники GitHub Releases/jsDelivr для обновлений;
- защищённый временный каталог обновления, минимальная проверка запуска с
  тайм-аутом 120 секунд и повторы операций с временно занятыми файлами;
- нативные Windows-ярлыки без зависимости от Windows Script Host и общий ярлык
  рабочего стола, не зависящий от учётной записи, подтвердившей UAC;
- локальный журнал установки для диагностики отказов;
- безопасное удаление, блокирующее junction, symlink и другие reparse point;
- режим `--safe-mode` для запуска интерфейса и восстановления без запуска Boost
  и первичной системной настройки.

Boostix не внедряется в процессы, не меняет файлы сторонних приложений, не
очищает standby list Windows и не уменьшает working set целевого приложения.
Доступная память Windows уже включает страницы кэша, которые система может
переиспользовать автоматически.

## Сборка

Требования:

- Windows 10/11;
- Windows PowerShell 5.1;
- .NET Framework 4.8 Developer Pack;
- Visual C++ runtime, необходимый поставляемому PresentMon.

```powershell
.\build.ps1
.\tests\Run-All.ps1
```

Результат успешной сборки:

- `dist\Boostix.exe`;
- `dist\Boostix-Setup-1.9.1.exe`;
- `dist\Boostix-Setup-Latest.exe`;
- `dist\MajesticBoost-Setup-1.9.1.exe` — только транспортный мост для
  обновления старых установок.

Сборка не считается готовой к публикации, если отсутствует хотя бы один
обязательный тест или любой тест завершился ошибкой.

## Обновления и релиз

Проверка обновлений работает по HTTPS через системный proxy. Для временных
сетевых ошибок выполняются ограниченные повторы с паузой. Разрешены только
заранее заданные адреса GitHub raw, GitHub Releases и jsDelivr; произвольный URL
из сети не запускается. Перед запуском установщика Boostix проверяет RSA-подпись
манифеста, разрешённый канал, размер, SHA-256, версию и идентичность продукта.
Ошибка криптографической проверки всегда блокирует пакет, а ошибка сети не
должна изменять текущую установку.

Для перехода установленных версий 1.3–1.8 сборка публикует изолированный
legacy-транспортный мост. Подписанный `update.json` остаётся в точной схеме из
пяти полей для старых клиентов, а `update-v2.json` описывает и мост, и основной
установщик Boostix. Только технические метаданные самого моста сохраняют прежнее
имя, необходимое строгой проверке старых версий. Мост содержит канонический
установщик Boostix; установленная программа, интерфейс, каталог и ярлыки остаются
Boostix. Проверки RSA, SHA-256, размера, версии и `ProductName` не отключаются.

Скачанный пакет помещается в уникальный временный каталог с защищёнными правами
для текущего пользователя, Administrators и SYSTEM. После повышения прав
установщик выполняет минимальную проверку готовности новой версии с лимитом 120
секунд и откатывает замену при неподтверждённом запуске. Временно занятые файлы
обрабатываются ограниченными повторами. Журнал установки сохраняется в
`%ProgramData%\Boostix\Logs\setup.log`, а при недоступности этого пути — в
`%TEMP%\Boostix-Setup.log`.

Перед stable-публикацией:

1. выполните `tests\Run-All.ps1` из чистого checkout;
2. подтвердите версию всех EXE и имён артефактов;
3. подпишите EXE доверенным Authenticode-сертификатом с RFC 3161 timestamp;
4. сформируйте и подпишите update-манифест;
5. повторно проверьте SHA-256 опубликованных файлов;
6. выполните lifecycle-проверку на чистой Windows.

Полные критерии находятся в
[`docs/RELEASE-CHECKLIST.md`](docs/RELEASE-CHECKLIST.md).

## Статус beta и совместимость

Целевая среда 1.9.1 BETA — Windows 10/11 x64 с интерактивным подтверждением UAC
и обычной установкой в Program Files. Это не обещание установки на любой
конфигурации. Полный E2E-прогон на чистых VM ещё продолжается; ARM64, запуск из
SYSTEM/session 0 и все варианты корпоративной proxy-аутентификации пока не
подтверждены.

EXE-файлы 1.9.1 пока **не имеют доверенной Authenticode-подписи**. RSA-подпись
манифеста защищает канал обновления, но не заменяет подпись издателя Windows.
Поэтому SmartScreen, WDAC или корпоративная политика могут показать неизвестного
издателя либо полностью заблокировать запуск. Отключать защиту Windows ради
установки не следует. Получение Authenticode-сертификата с RFC 3161 timestamp и
завершение VM-матрицы остаются обязательными блокерами перед stable-релизом.

## Данные и безопасность

Boostix работает локально и не отправляет телеметрию. Сетевые запросы
используются только для проверки и загрузки обновления. Диагностический экспорт
создаётся только по действию пользователя.
