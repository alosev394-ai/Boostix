# Boostix

Boostix готовит Windows к игре: включает план питания на максимум, закрывает
выбранные фоновые программы, следит за памятью во время игры и показывает, что
изменилось. Всё, что Boostix меняет в системе, можно вернуть.

Текущая версия — **3.0**, первая стабильная. Boostix не обещает определённый
прирост FPS: результат зависит от компьютера, драйверов, игры и сцены. Честно
сравнить можно встроенным замером FPS на одном компьютере и в одной сцене.

## Как пользоваться

1. Запустите игру.
2. В Boostix нажмите **«Выбрать»** и укажите игру.
3. Нажмите на датчик **Boost** или Enter. Стрелка уйдёт в янтарную зону:
   Boost включён. Повторное нажатие выключает его.

Прямо из игры Boost включается и выключается сочетанием **Ctrl+Alt+B**. Это
же действие есть в меню значка Boostix рядом с часами.

При первом запуске Boostix предложит один раз настроить Windows для игр:
питание, игровой режим, меньше фоновых эффектов. Перед этим он сохранит
текущие настройки; вернуть их можно кнопкой «Восстановить Windows» в
настройках.

## Разделы

- **Главная** — выбор игры, датчик Boost и одна оценка: готов ли компьютер.
- **Проверка ПК** — память, питание, место на диске и другие проверки.
- **Фоновые программы** — что нагружает компьютер в фоне. Закрыть программу
  можно кнопкой в её строке; сам Boostix ничего не закрывает.
- **История** — что происходило во время игры и замер FPS до и после.
- **Игры** — список игр. «Авто» запускает Boost вместе с игрой.
- **Настройки** — какие программы закрывать при запуске Boost, горячая
  клавиша, сворачивание в трей, сбор диагностики для поддержки.

## Чего Boostix не делает

- не «чистит» оперативную память и не урезает память игры;
- не завершает программы принудительно;
- не вмешивается в игру, её файлы и античит;
- не отключает антивирус, SmartScreen, UAC и брандмауэр.

## Установка

Скачайте `Boostix-Setup-3.0.0.exe` со страницы релиза и сверьте SHA-256 с
`SHA256SUMS.txt`. Дальше Boostix обновляется сам.

Файлы Boostix пока **не подписаны сертификатом Authenticode**, поэтому Windows
может показать предупреждение SmartScreen о неизвестном издателе. Не
отключайте защиту Windows ради установки: в окне SmartScreen нажмите
«Подробнее» и проверьте, что файл скачан со страницы релиза Boostix.

Нужны Windows 10 или 11 (64-бит) и .NET Framework 4.8.

## Для разработчиков

Требования к сборке: Windows PowerShell 5.1, .NET Framework 4.8 Developer Pack,
Visual C++ runtime для поставляемого PresentMon.

```powershell
.\build.ps1
.\tests\Run-All.ps1
```

Артефакты сборки:

- `dist\Boostix.exe`;
- `dist\Boostix-Setup-3.0.0.exe` и `dist\Boostix-Setup-Latest.exe`;
- `dist\MajesticBoost-Setup-3.0.0.exe` — технический мост обновления старых
  установок 1.3–1.9; установленный продукт остаётся Boostix.

Сборка не готова к публикации, если любой обязательный `Test-*.ps1` пропущен или
завершился ошибкой.

Обновления: подписанный RSA-манифест `update-v3.json`, проверка размера, SHA-256,
PE-структуры, версии и `ProductName`, защищённая подготовка, проверка запуска
новой версии и откат при сбое. Подробнее — в [SECURITY.md](SECURITY.md).

Технические границы: точная цель закрепляется по PID, времени запуска и пути
EXE; контроль памяти во время сеанса отфильтровывает краткие всплески; план
питания сеанса включается только от сети и восстанавливается после игры;
замер FPS сравнивает четыре минутных прохода (без Boost, с Boost, с Boost, без
Boost); поиск причины вылета опирается на журналы Windows и не выдаётся за
диагноз.
