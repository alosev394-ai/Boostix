# Boostix

Boostix — локальное приложение для подготовки Windows к игровой или другой
ресурсоёмкой сессии. Оно показывает фактическое состояние памяти и выбранного
процесса, помогает оценить фоновую нагрузку, а системные изменения ограничивает
документированным восстанавливаемым набором. Приложение не связано с конкретной
игрой или лаунчером.

Текущий канал — **2.0.0 BETA**. Boostix не обещает фиксированный прирост FPS:
результат зависит от оборудования, драйверов, температуры, сцены, настроек и
фоновой нагрузки. Сравнивать результат следует на одном ПК и в одном сценарии.

## Возможности 2.0

- **Управляемая подготовка Windows.** Перед elevated-изменениями требуется
  отдельное подтверждение. Состояние разрешённых параметров сохраняется для
  восстановления; уже подходящее значение не перезаписывается без причины.
- **Точная игровая цель.** Пользователь выбирает процесс, а Boostix закрепляет
  его по PID, времени запуска и полному пути. Повторное использование PID другим
  процессом не считается продолжением той же сессии.
- **Session Guard.** Во время Boost отслеживаются доступная физическая память,
  commit reserve, файл подкачки и память точного целевого процесса. Краткие
  всплески фильтруются гистерезисом; предупреждение не выдаётся по одному
  случайному измерению.
- **Background Impact.** Фоновые приложения оцениваются без изменений системы.
  Закрытие выполняется только после выбора пользователя и только штатным
  запросом приложению. Принудительное завершение процесса не используется.
- **Proof Mode.** Управляемое сравнение из четырёх 60-секундных прогонов по схеме
  Baseline → Boost → Boost → Baseline. Контекст цели закрепляется, а итог
  показывает FPS, 1% low, P95 и вариативность. Результат относится только к
  выполненному сценарию и не является обещанием универсального ускорения.
- **Crash Assistant.** После завершения точного целевого процесса Boostix ищет
  ограниченные по времени записи Windows Error Reporting и Application Error.
  Это корреляция свидетельств, а не утверждение, что Boostix установил причину
  сбоя.
- **План питания на сессию.** Разрешённый план Boostix может включаться только от
  сети переменного тока. После сессии восстанавливается точный предыдущий план;
  если пользователь или Windows переключили план вручную, это изменение не
  перезаписывается.
- **Установка и обновление.** Подписанный RSA-манифест, SHA-256, проверка размера,
  PE и идентичности продукта, защищённый staging, прогресс, health handshake и
  транзакционный rollback. Сохранён путь обновления установок 1.3–1.9 через
  совместимый legacy-мост.
- **Локальная диагностика.** Отчёты хранятся на компьютере. Сетевые запросы нужны
  только для проверки и загрузки обновлений; экспорт выполняется пользователем.

## Безопасные границы

Boostix не:

- очищает standby list или системный файловый кэш;
- уменьшает working set игры либо другого целевого процесса;
- вызывает принудительный GC ради показного уменьшения памяти;
- принудительно завершает выбранные фоновые процессы;
- внедряется в процессы, меняет игровые файлы или обходит anti-cheat;
- отключает антивирус, SmartScreen, UAC, брандмауэр или проверку подписей.

Windows сама переиспользует доступные кэшированные страницы. Агрессивная
«очистка RAM» может увеличить повторные чтения и статтеры, поэтому она не входит
в Boostix 2.0.

## Требования и сборка

Целевая среда beta-канала:

- Windows 10/11 x64;
- интерактивная пользовательская сессия и подтверждение UAC для elevated-шагов;
- Windows PowerShell 5.1;
- .NET Framework 4.8 для запуска и Developer Pack для сборки;
- Visual C++ runtime, необходимый поставляемому PresentMon.

```powershell
.\build.ps1
.\tests\Run-All.ps1
```

Основные артефакты успешной сборки:

- `dist\Boostix.exe`;
- `dist\Boostix-Setup-2.0.0.exe`;
- `dist\Boostix-Setup-Latest.exe`;
- `dist\MajesticBoost-Setup-2.0.0.exe` — только технический мост обновления
  старых установок; установленный продукт остаётся Boostix.

Сборка не готова к публикации, если отсутствует обязательный тест или любой
обязательный тест завершился ошибкой.

## Обновления

Updater использует HTTPS, системный proxy и ограниченные повторы только для
временных сетевых ошибок. Манифест и подпись загружаются с разрешённых адресов;
исполняемый файл принимается только после проверки RSA-метаданных, размера,
SHA-256, версии, PE-структуры и `ProductName`. Ошибки сети, локального хранилища,
UAC и целостности показываются раздельно. Ни одна из них не должна повреждать
текущую установку.

Для установок 1.3–1.9 сохраняется legacy-канал перехода. Старые клиенты нельзя
исправить задним числом, поэтому в сети, где их единственный endpoint
заблокирован, может потребоваться ручной запуск официального versioned
installer со сверкой `SHA256SUMS.txt`.

Подробности: [поддержка](SUPPORT.md),
[устранение проблем](TROUBLESHOOTING.md) и
[матрица тестирования](docs/TEST-MATRIX.md).

## Статус BETA

Исполняемые файлы 2.0.0 BETA пока **не имеют доверенной Authenticode-подписи**.
RSA-подпись манифеста защищает канал обновлений, но не заменяет подпись издателя
Windows. SmartScreen, WDAC, AppLocker или корпоративная политика могут показать
неизвестного издателя либо заблокировать запуск. Не отключайте защиту Windows
ради установки.

До завершения реальной VM/аппаратной матрицы, длительного RC и code signing
2.0.0 публикуется только как prerelease. Универсальная совместимость и
гарантированный прирост производительности не заявляются.
